# Khwarizmi Club

**Learn Beyond Limits. Speak Without Borders.**

A mobile-first school language community website with an editorial visual identity.

## Included
- Responsive, multi-section public website
- English / Persian interface toggle
- Interactive English mini-quiz
- Installable PWA manifest and lightweight offline shell
- Magazine, English Lab, Debate Arena, Events, About and Join sections

## Deploy
The site is static and can be hosted with GitHub Pages. In the repository settings, open **Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

## Important
This first release is a front-end foundation. It does not yet include member accounts, persistent submissions, moderation tools or a database. Those require a secure backend and school-approved account/data policies. Never put private API keys in this public repository.
